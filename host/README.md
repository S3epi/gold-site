# نرخینو روی هاست PHP + MySQL (cPanel)

این پوشه بستهٔ استقرار روی هاست اشتراکی است. هیچ Node.js لازم نیست؛ فقط PHP 8.1+، MySQL/MariaDB، cURL و mod_rewrite.

## ۱) ساخت پایگاه داده

در cPanel → MySQL Databases:

1. یک دیتابیس بسازید (مثلاً `USER_narkhino`).
2. یک کاربر بسازید و به دیتابیس با دسترسی کامل وصل کنید.
3. (اختیاری) فایل `schema.sql` را در phpMyAdmin اجرا کنید؛ API در اولین درخواست خودش جدول‌ها را می‌سازد.

## ۲) فایل تنظیمات خارج از public_html

فایل `narkhino-config.php.example` را به `narkhino-config.php` تغییر نام دهید و در **پوشهٔ بالای public_html** بگذارید:

```
/home/USER/narkhino-config.php
/home/USER/public_html/api/index.php
```

مقدار `NK_DB_DSN`، `NK_DB_USER` و `NK_DB_PASS` را با اطلاعات دیتابیس پر کنید و `NK_SITE_URL` را برابر آدرس سایت (با `https://`) بگذارید.

`NK_OWNER_PASSWORD` به‌صورت پیش‌فرض هش SHA-256 رمز فعلی پنل است و همان رمز قبلی کار می‌کند. برای رمز تازه:

```bash
php tools/hash-password.php 'رمز-جدید'
```

خروجی bcrypt را جای مقدار فعلی بگذارید.

## ۳) ساخت و آپلود سایت

روی رایانه:

```bash
npm run build:host
```

سپس محتوای `web/dist` را در `public_html` بریزید و پوشهٔ `api` را از `host/public_html/api` کنار `index.html` قرار دهید. فایل `.htaccess` این پوشه را هم در `public_html` بگذارید.

> آدرس سایت باید روی ریشهٔ دامنه باشد (`/`). اگر سایت داخل زیرپوشه است، `--base=/زیرپوشه/` بدهید و شرط بازنویسی API را هم متناسب تغییر دهید.

## ۴) پنل مالک

پنج ضربهٔ سریع روی نشان سایت یا باز کردن `#owner`.

با باز شدن پنل، اگر API در دسترس باشد حالت «سرور» فعال می‌شود و این بخش‌ها کار می‌کنند:

- **اعلان:** هر بازدیدکننده یک بار متن را می‌بیند و با «خواندم» برای همیشه (روی همان دستگاه و روی سرور) حذف می‌شود.
- **ربات تلگرام:** توکن + یوزرنیم/لینک کانال؛ سپس «تست اتصال و ادمین» / «رفرش بات» / «ارسال قیمت‌ها».
  خطاها فارسی‌اند: توکن نامعتبر، کانال پیدا نشد، ربات ادمین نیست، نداشتن اجازهٔ ارسال و…
- **API:** ساخت کلید با دامنهٔ مجاز؛ کلید را در هدر `X-Api-Key` یا پارامتر `key` بفرستید.

در حالت استاتیک (بدون PHP) فقط تنظیم کانال در همان مرورگر ذخیره می‌شود و بقیهٔ گزینه‌ها پیام راهنما نشان می‌دهند.

## ۵) API اختصاصی

`GET /api/health` عمداً `ok:false` برمی‌گرداند تا تابلوی خود سایت همیشه مستقل و مستقیم از بازار بخواند و API عمومی فقط با کلید باز شود.

مسیرهای محافظت‌شده (کلید + دامنهٔ ثبت‌شده):

```
GET /api/v1/prices
GET /api/v1/gold
GET /api/v1/coins
GET /api/v1/currencies
GET /api/v1/ounce
GET /api/v1/history?instrument=gold18&period=1m
```

نمونه:

```bash
curl -H "X-Api-Key: nk_..." "https://example.com/api/v1/prices"
```

پاسخ قیمت‌ها به تومان است؛ انس به دلار. کلید بدون دامنه، از همهٔ دامنه‌ها کار می‌کند و کلید با دامنه فقط از همان Origin/Referer.

## ۶) تست سریع

```bash
php -l public_html/api/index.php
php -l public_html/api/lib.php
curl "https://example.com/api/health"
curl "https://example.com/api/v1/announcements/active?device=testdevice123"
```

اگر `/api/health` پاسخ JSON داد، مسیر‌دهی درست است (ok آن false است، این طبیعی است).

## نکات امنیتی

- فایل تنظیمات هرگز داخل `public_html` نباشد.
- کش قیمت در `tmp` سرور ساخته می‌شود؛ اگر مسیر دیگری می‌خواهید `NK_CACHE_DIR` را تنظیم کنید.
- نشست پنل با کوکی HttpOnly/SameSite=Lax است و تلاش‌های ورود محدود می‌شوند.
- توکن ربات و کلیدهای API فقط در پنل مالک (پس از ورود) دیده می‌شوند.
