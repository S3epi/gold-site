# مثقال‌یار | MesghalYar

تابلوی تک‌صفحه‌ای قیمت طلا، سکه و ارز برای بازار ایران، با ماشین‌حساب ارزش ذاتی و حباب (مثبت و منفی).

**نسخهٔ زنده:** https://s3epi.github.io/gold-site/

> مثقال‌یار مارکت‌پلیس نیست؛ فقط قیمت را نمایش می‌دهد و محاسبهٔ شفاف ارائه می‌کند.

## امکانات

- طلا: گرم ۱۸ عیار، ۲۴ عیار، ۷۴۰ و مثقال
- سکه: امامی، بهار آزادی، نیم، ربع
- ارز: دلار، یورو، درهم، پوند، لیر (تومان) و انس جهانی
- **ماشین‌حساب ارزش ذاتی:** وزن/تعداد را وارد کنید تا ارزش ذاتی از انس و دلار، مظنهٔ بازار و حباب مثبت/منفی محاسبه شود
- **حباب هر طلا و سکه** روی کارت‌ها با درصد و مبلغ؛ سبز برای زیر ارزش و قرمز برای بالای ارزش
- نمودار تاریخچه با بازه‌های ۲۴ ساعت، ۱ هفته، ۱ ماه، ۳ ماه، ۶ ماه، ۱ سال و همه (بازه‌های بدون داده غیرفعال‌اند)
- به‌روزرسانی خودکار هر ۲۰ ثانیه؛ در تب پنهان هر ۹۰ ثانیه با backoff
- طراحی اختصاصی سرمه‌ای/طلایی، RTL و ریسپانسیو ۳۲۰–۱۹۲۰

## محاسبه‌ها

ارزش ذاتی هر گرم طلای خالص:

```
انس (دلار) × نرخ دلار (تومان) ÷ ۳۱٫۱۰۳۴۷۶۸
```

ارزش هر گرم با عیار مشخص = ارزش گرم خالص × عیار

- ۱۸ عیار = ۰٫۷۵ · ۲۴ عیار = ۰٫۹۹۹ · ۷۴۰ = ۰٫۷۴
- مثقال = ۴٫۶۰۸۳ گرم با عیار ۰٫۷۰۵
- سکهٔ امامی/بهار: ۸٫۱۳۳ گرم با عیار ۰٫۹ · نیم: ۴٫۰۶۶۵ · ربع: ۲٫۰۳۳۲۵

حباب = مظنهٔ بازار − ارزش ذاتی (درصد نسبت به ارزش ذاتی). مقدار مثبت یعنی گران‌تر از ارزش، منفی یعنی ارزان‌تر.

## معماری

- npm workspaces: `shared` (منطق بازار و محاسبات)، `server` (Fastify + SQLite)، `web` (React + Vite)
- فرانت دو حالت دارد:
  - **سرور اختصاصی:** وقتی `/api/health` پاسخ دهد
  - **استاتیک:** روی GitHub Pages، دریافت مستقیم از سرویس‌های بازارِ سازگار با مرورگر
- انس جهانی از دو سرویس مستقل با فالبک خوانده می‌شود؛ در نبود آن‌ها مقدار جایگزین بازار داخلی استفاده می‌شود
- هیچ قیمت، تاریخچه یا نقطهٔ نموداری ساختگی تولید نمی‌شود؛ داده‌های قدیمی «کهنه» یا «تأخیری» برچسب می‌خورند

## اجرا

```bash
npm install
npm run build:shared
npm run dev        # API: 3001 · Web: 5173
```

بیلد و اجرای یکپارچه:

```bash
npm run build
npm start
```

انتشار GitHub Pages با هر push روی `main` انجام می‌شود (`.github/workflows/pages.yml`).
