# زرنما | ZerNama

تابلوی تک‌صفحه‌ای قیمت طلا، سکه و ارز برای بازار ایران؛ با نمودار تاریخچهٔ واقعی و برچسب‌گذاری صادقانهٔ وضعیت داده.

**نسخهٔ زنده (GitHub Pages):** https://s3epi.github.io/gold-site/

> زرنما مارکت‌پلیس نیست؛ فقط قیمت‌ها را نمایش می‌دهد.

## آنچه نمایش داده می‌شود

- طلا: گرم ۱۸ عیار، گرم ۲۴ عیار، طلای دست‌دوم (۷۴۰)، طلای آب‌شده (عمده)، مثقال
- سکه: امامی، بهار آزادی، نیم، ربع (سکه یک‌گرمی به‌دلیل نبود منبع معتبر نمایش داده نمی‌شود)
- ارز: دلار، یورو، درهم، پوند، لیر (تومان)
- انس جهانی طلا (دلار)
- مرجع محاسباتی: ارزش نظری هر گرم/سکه از انس و دلار و حباب سکه

هر قلم چهار وضعیت دارد: **زنده / تأخیری / کهنه / ناموجود** (و «اختلاف منابع» وقتی دو منبع بیش از حد اختلاف داشته باشند). مقادیر بدون منبع هرگز ساخته نمی‌شوند.

## معماری

- npm workspaces: `shared` (منطق بازار)، `server` (Fastify + SQLite)، `web` (React + Vite)
- حالت دوگانهٔ داده در فرانت:
  - **سرور اختصاصی:** وقتی API خودمان (`/api/health`) در دسترس است
  - **استاتیک:** روی GitHub Pages، مستقیم از منابع عمومی CORSدار
- تاریخچهٔ واقعی: TGJU summary-table-data؛ در حالت استاتیک، فید لحظه‌ای از TGJU widget + gold-api (با فالبک TGJU) خوانده می‌شود
- نمودار: lightweight-charts با بازه‌های ۲۴ ساعت، ۱ هفته، ۱ ماه، ۳ ماه، ۶ ماه، ۱ سال، همه؛ بازه‌های بدون داده غیرفعال می‌شوند
- به‌روزرسانی خودکار هر ۲۰ ثانیه (پنهان‌بودن تب: ۹۰ ثانیه، با backoff تا ۱۲۰ ثانیه)

## اجرای محلی (حالت کامل با سرور)

```bash
npm install
npm run build:shared
npm run dev
```

- API: http://localhost:3001
- Web: http://localhost:5173

فقط فرانت:

```bash
npm run build:shared
npm run dev:web
```

## بیلد و انتشار

```bash
npm run build          # shared + web + server
npm start              # سرور با سرو کردن web/dist
```

GitHub Pages به‌صورت خودکار با هر push روی `main` از طریق `.github/workflows/pages.yml` منتشر می‌شود.

## نکتهٔ صداقت داده

- در حالت استاتیک، سرویس TGJU زمان دقیق مظنه را در دسترس قرار نمی‌دهد؛ بنابراین اقلام داخلی با وضعیت **تأخیری** و برچسب «مظنهٔ روزانه منبع» نمایش داده می‌شوند، نه «زنده».
- تاریخچه فقط از داده‌های واقعی ثبت‌شدهٔ منبع ساخته می‌شود؛ نقطهٔ ساختگی اضافه نمی‌شود.
- ارزش مرجع و حباب، محاسبهٔ نظری است و قیمت معامله نیست.

## وضعیت

- ✅ پیاده‌سازی‌شده: UI تک‌صفحه‌ای، تمام کارت‌ها و بخش‌ها، نمودار تعاملی با تلمچارت، انتخاب بازه، وضعیت‌ها، حباب سکه، فالبک انس، استقرار Pages
- ✅ بررسی‌شده: بیلد production، تایپ‌چک، نمایش دادهٔ واقعی در مرورگر (حالت استاتیک)
- ⏳ آزمون نکرده: اجرای کامل سرور + پایگاه‌داده در محیط استقرار، تست‌های واحد/چند‌مرورگری جامع
- ❌ ناقص/خارج از محدوده: سکه یک‌گرمی (منبع معتبر ندارد)، Nobitex/Bonbast (از این شبکه در دسترس نیستند؛ آداپتر غیرفعال)
